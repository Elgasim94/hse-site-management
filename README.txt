HSE Site Management V1 - LOCAL PROTOTYPE

Files: index.html, manifest.webmanifest, icon.svg, sw.js

To preview locally: open index.html in a browser. To install as PWA on iPhone/Android, host the entire folder on an HTTPS site. PWA installation requires an appropriate browser and HTTPS hosting.

This is NOT yet a multi-user production app. Records are saved only in localStorage on the current device. No authentication, cloud database, photo storage, cross-device sync, automated PDF reports, or secure access control is implemented. Do not enter sensitive data or use this prototype as an official HSE record.

Next development step: choose and configure a free-tier backend with per-user authentication, access controls, photo storage, and cloud syncing; then add full inspections and official reporting.
